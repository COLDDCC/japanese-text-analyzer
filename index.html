需要用本地服务器打开

直接双击 index.html 是打不开的：浏览器禁止 file:// 页面使用 ES 模块、Web Worker 和 fetch，而分词器和词典全靠这三样加载。

在项目目录里跑 npm install，然后 npm run dev， 打开它打印出来的地址即可。部署到 Cloudflare Pages 也可以。

This page needs a local server

Opening index.html from disk cannot work: browsers block ES modules, Web Workers and fetch on file:// URLs, and the tokenizer and dictionary need all three.

Run npm install and then npm run dev in the project folder, and open the URL it prints. Deploying to Cloudflare Pages works too.
